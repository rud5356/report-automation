# 일일 업무보고 자동화

노션 **Today To-do** 데이터베이스에서 오늘 업무를 자동으로 읽어와 보고서를 생성합니다.

## 폴더 구조

```
업무보고/
├── README.md               # 이 파일
├── fetch_notion.py         # 노션 API 호출 → today_input.txt 생성
├── .env                    # Notion 토큰 (git 제외)
└── YYYY-MM-DD_업무보고.txt  # 날짜별 생성된 보고서
```

## 사용 방법

Claude Code에서 슬래시 커맨드 실행:

```
/업무보고
```

자동으로 노션에서 오늘 날짜 항목을 가져와 보고서를 저장합니다.

## 노션 데이터베이스 속성

| 속성 | 역할 |
|------|------|
| 날짜 | 오늘/내일 필터링 기준 |
| 할일 | 업무 제목 |
| 프로젝트 | 소속 프로젝트 (Biofin, etc) |
| 업무구분 | 행정업무, 공부 등 |
| 상태 | 시작 전 / 진행 중 / 완료 |
| 비고 | 액션/후속사항 |

## 보고서 생성 규칙

- **오늘 날짜** 항목 → `[금일 진행 사항]`
- **내일 날짜** 항목 → `[진행 예정 사항]` (없으면 오늘 미완료 항목)
- 비고가 있으면 `→` 액션으로 표시

## 초기 설정

`.env` 파일에 Notion 토큰과 데이터베이스 ID 입력:

```
NOTION_TOKEN=secret_...
NOTION_DATABASE_ID=...
```

- 토큰: [notion.so/my-integrations](https://www.notion.so/my-integrations)
- 데이터베이스에 integration 연결 필요 (페이지 `•••` → 연결)
